# Concept guitars

Extra guitar ideas for the Louie guitar app, beyond the seven Road guitars in `docs/guitars/pics/`. These are concepts
for Graham to pick from, not wired into the app.

Every image follows the Road guitar rules: the whole guitar upright and straight, headstock at the top, the rounded 3+3
headstock, a flat #FF00FF background, 768 × 1376 at the same framing as `docs/guitars/pics/cutaway-sunburst.jpg` (top
of the headstock at y≈65, neck centred), and no logos, brand names or text. Bodies are original outlines; the
inspiration charts were used only for the general feel.

## Notes

- Painted with an image model using the lineup (`docs/road-ready/images/r10-11-guitar-lineup.jpg`) and
  `cutaway-sunburst.jpg` as references, then keyed and re-framed so the background is exactly #FF00FF.
- All 16 are shown at the same scale (the image model's native size); relative body sizes are approximate.
- No headstock close-ups yet for the concepts.
