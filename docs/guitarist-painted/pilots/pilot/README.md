# Painted layer pilot

One painted figure, then five edits of that same picture. Three change only the hair (curly, long, pixie). Two change only the top (flannel, leather).

Each layer is the pixels that changed, cut out with a soft edge, on the same 800 by 800 canvas. `body.webp` is the base with the shared hair and the red shirt lifted out, so a hair layer and a top layer sit on it. `base.webp` is the whole painted figure.

The edges are not clean. A pink rim stays around the silhouette, some of the original hair shows through, and the collar has gaps. The stack picture next to the pull request shows that. This pilot is not wired into the app.
