# Painted layer pilot, round 2

The base is a buzz cut and a dark grey crew neck, so a bigger hair style or a jacket has nothing bright to leave behind.

The image tool cannot take a mask. Each variant was painted as an edit, then every pixel outside the hair mask or the torso mask was put back from the base. The face is the base face. The layer is only the pixels inside the mask that changed, choked by 1 pixel, with a soft edge of about 2 to 3 pixels.

`body.webp` keeps the neck and the collar, so the background does not show through. The hair files are curly, long, and pixie. The tops are flannel and leather.

Zoomed in, the hairline is still a seam and the outer edge still carries a pink fringe from the magenta backdrop. This is not clean enough to build the full parts list.
