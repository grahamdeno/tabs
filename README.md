# Tabs

A personal guitar tabs PWA. Offline-first, localStorage only, no accounts.

Paste ASCII tabs, search your library, auto-scroll, and add to your home screen.

Built in the same style as [threads](https://github.com/grahamdeno/threads) and [scales](https://github.com/grahamdeno/scales).

## Live

Once GitHub Pages is enabled on the `main` branch (root), the app will be at:

`https://grahamdeno.github.io/tabs/`

## Features

- Library with search and favorites
- ASCII tab viewer with auto-scroll
- Add/edit by pasting tab text
- Export / import JSON backup
- Fully offline after first load
- Installable as a PWA on iOS and Android

## Development

Open `index.html` in a browser. Data lives in `localStorage` under `tabs-v1`.
